# Awesome Claude Code GitHub

*Unofficial community list for the Claude Code GitHub integration. Not affiliated with Anthropic. All trademarks belong to their owners.*

A curated list of documentation, articles and tools for the Claude Code GitHub integration: running Claude Code in the cloud against a connected GitHub repository, running it inside GitHub Actions, and the surrounding docs on skills, memory and sessions. Only links that the cited sources themselves link or name are included, so the list is short and every entry is real.

> Need a site or app rather than an agent? [Try Begin.sh - prompt or URL in, static site or Expo app zip out](https://begin.sh?utm_source=github&utm_medium=ugc&utm_campaign=awesome-claude-code-github&utm_content=readme-top&utm_term=tier-r).
